📊 API отчетов

Создание отчета

Для создания отчета отправьте POST запрос или нажмите кнопку:

POST /api/reports

Получение отчета

Для получения отчета отправьте GET запрос:

GET /api/reports/{id}

Пример: GET /api/reports/1

Статусы отчетов

  • Создан - отчет в процессе формирования
  • Завершен - отчет готов к просмотру
  • Ошибка - при формировании произошла ошибка
